## 🌟 Что внутри базы знаний

### ⚡ 1. Интерактивные блоки предохранителей и реле
* **4 блока:** Салон (P01), Под капотом (E01), Силовые предохранители АКБ (E02/E03).
* **Мгновенный поиск:** найдите предохранитель по названию устройства (прикуриватель, регистратор, обогрев сидений, фары, дворники, бензонасос, муфта полного привода, OBD2).
* **Пресеты в 1 клик:**
  * 📹 *Подключение видеорегистратора* (выделение постоянного плюса B+ и провода ACC).
  * 🔌 *Розетки 12V и разъемы USB*.
  * 🔥 *Подогревы сидений, руля и стекол*.
  * 💡 *Фары, ПТФ и освещение салона*.
  * 🌧️ *Стеклоочистители и омыватель*.
  * 🔍 *Диагностический разъем OBD2*.
* Цветовая маркировка номиналов (5A, 7.5A, 10A, 15A, 20A, 25A, 30A, 40A, 50A, 60A).
* Точные физические схемы расположения блоков с подсказками (где находится щипцы для извлечения, где блок в торпедо за бардачком).

---

### 🗺️ 2. Атлас электрических схем (SVG-вектор)
* **87+ оригинальных электросхем** Changan CS55 Plus.
* Все схемы оцифрованы в **векторный SVG** — зум без потери четкости, кристально читаемые номера пинов, цвета проводов и блоки управления.
* Встроенный просмотрщик: панорамирование, масштабирование, полноэкранный режим, скачивание схемы в 1 клик.
* Поиск схем по узлам: ДВС Blue Core 1.5T, 7DCT, ЭУР, ABS/ESP, мультимедиа, климат-контроль, подушки безопасности, полный привод.

---

### 🔧 3. Сервисные процедуры и скрытые инструкции
Пошаговые проверенные инструкции с таймингами:
1. **Сброс межсервисного интервала ТО** («Гаечный ключ» на приборной панели).
2. **Сервисный режим стеклоочистителей** (подъем щеток зимой и для замены).
3. **Сервисный режим задних тормозных колодок (EPB)** (электронный развод суппортов без диагностического сканера).
4. **Аварийный перевод 7DCT в нейтраль (N)** (механическая разблокировка селектора при севшем аккумуляторе для буксировки/эвакуатора).
5. **Обучение автодоводчиков стеклоподъемников и люка** (инициализация антизащемления после сброса клеммы аккумулятора).
6. **Привязка датчиков давления в шинах (TPMS)** (калибровка датчиков 433 МГц после сезонной смены колес).
7. **Адаптация дроссельной заслонки** после чистки.

---

### ⚠️ 4. Сканер 1 391 кода неисправностей (DTC)
* База кодов OBD-II (SAE J2012) + дилерские коды Changan:
  * `P0xxx / P1xxx / P2xxx` — двигатель и трансмиссия.
  * `U0xxx / U1xxx` — шины данных CAN / LIN и блоки управления.
  * `C0xxx / C1xxx` — тормозная система, рулевое управление, шасси.
  * `B0xxx / B1xxx` — кузовная электроника, подушки безопасности, освещение.
* Мгновенный поиск по коду ошибки (например, `P0300`, `U0100`, `P0420`) или по симптому на русском языке («пропуск зажигания», «датчик кислорода», «потеря связи»).
* Копирование кода в буфер в 1 клик.

### 📑 5. Интерактивный навигатор по мануалу (1 719 страниц)
* Полный интерактивный каталог из 11 глав и 40+ разделов официального руководства по ремонту и эксплуатации Changan.
* Поиск по агрегатам, номерам страниц и разделам.

---

### 📊 6. Паспорт ТТХ и объемы технических жидкостей
* Спецификации и точные заправочные объемы:
  * Моторное масло: допуск **0W-20 SP**, объем 4.0 л.
  * Трансмиссионное масло 7-ступенчатого «мокрого» робота **Changan 7DCT** (допуск Changan DCTF).
  * Тормозная жидкость: **DOT 4 Class 6** (для систем с ESP).
  * Антифриз: карбоксилатный **G12+ / G12++** (розовый).
* Габариты, масса, крутящий момент, давление в шинах (2.3 бар).

## 🚀 Быстрый запуск на компьютере

```bash
# Клонируйте репозиторий
git clone https://github.com/scanek/changan-cs55-wiki.git
cd changan-cs55-wiki

# Установите зависимости
npm install

# Запустите локальный сервер
npm run dev
```

Откройте в браузере: `http://localhost:5173`.

---

## 🐳 Запуск в Docker

```bash
docker build -t changan-cs55-wiki .
docker run -d -p 8080:80 --name changan-wiki changan-cs55-wiki
```

Откройте в браузере: `http://localhost:8080`.
